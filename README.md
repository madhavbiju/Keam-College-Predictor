# KEAM College Predictor

A fast, single-page static web application to predict engineering college allotments in Kerala based on candidate ranks and reservation categories from preceding years' KEAM admission allotments.

## Tech Stack

- **Structure**: HTML5
- **Style**: CSS3, Tailwind CSS CDN
- **Logic**: Vanilla ES6 JavaScript
- **Data Source**: Static JSON database (`dataset.json`)

## Local Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the local server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:8087](http://localhost:8087) in your browser.
